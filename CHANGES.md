# Исправление блокировки выполнения команд при запуске GUI-приложений

## Проблема

AI-агент блокировался при выполнении команд, которые запускают GUI-приложения (например, `dotnet run`, `python app.py`, и т.д.), до тех пор пока пользователь не закроет запущенное окно. Это происходило потому, что `CommandRunner.ExecuteAsync` всегда ждал завершения процесса с помощью `WaitForExitAsync`.

## Решение

Реализован механизм детектирования "молчаливых" процессов:

### Логика работы

1. **Ранняя детекция GUI-приложений** - известные GUI-приложения (notepad, calc, code, браузеры) запускаются асинхронно через `LaunchGuiApplicationAsync`

2. **Детекция по поведению** - для всех остальных команд:
   - Процесс запускается с перенаправлением stdout/stderr
   - Вывод читается в реальном времени через `ReadStreamAsync` в StringBuilder
   - Если процесс жив и **не производит никакого вывода в течение 3 секунд**, считается GUI-приложением
   - В этом случае процесс отпускается в фон с сообщением "Application launched and running in background."
   - Если процесс начал выводить данные или завершился, обрабатывается как обычная консольная команда

### Что это даёт

- **`dotnet run`** для GUI-приложения: запустится, агент получит управление через 3 секунды
- **`python gui_app.py`**: аналогично
- **`dir`, `git status`, `dotnet build`**: работают как раньше, вывод захватывается полностью
- **Известные GUI-приложения** (`notepad`, `code`): запускаются сразу асинхронно без ожидания

### Технические детали

**Файл:** `C:\Users\aikos\source\repos\RedBloom\RedBloom\Services\Ai\CommandRunner.cs`

**Изменения:**

1. `ExecuteAsync()` - добавлен цикл ожидания с проверкой вывода каждые 100мс
2. `ReadStreamAsync()` - новый метод для чтения потоков в StringBuilder с возможностью мониторинга

**Параметры:**
- Порог тишины (silence threshold): 3 секунды
- Интервал проверки: 100 миллисекунд
- Общий таймаут команды: 2 минуты (без изменений)

## Тестирование

После сборки протестируйте:
1. Команду с GUI: `dotnet run` (для WPF/WinForms проекта)
2. Консольную команду: `dir`, `dotnet build`
3. Известное GUI-приложение: `notepad test.txt`

Агент должен продолжить работу сразу после запуска GUI-приложений, не дожидаясь их закрытия.
